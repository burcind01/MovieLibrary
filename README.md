# MovieLibrary

Een eenvoudige webapplicatie om een eigen filmbibliotheek te beheren.

## Functionaliteiten

* Films bekijken
* Films toevoegen
* Films aanpassen
* Films verwijderen
* Poster toevoegen via URL
* Rating geven van 1 t/m 5
* Bijhouden of een film gezien is

## Technologie

* HTML & CSS
* Bootstrap
* JavaScript
* PHP
* MySQL
* PDO

## Installatie

1. Start Apache en MySQL in XAMPP.
2. Plaats het project in `C:\xampp\htdocs\MovieLibrary`.
3. Maak de database `movie_library` aan in phpMyAdmin.
4. Open:

`http://localhost/MovieLibrary/`
